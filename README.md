# 🎱 八球オラクル ｜ 令和版マジック8ボール

問いを一つ胸に、球をふる。7人の占い師のいずれかが、口調を変えてお告げを返す
── 昭和のマジック8ボールを令和版にした、1ファイル完結のWebトイ。

**▶ [https://eightball.vercel.app](https://eightball.vercel.app)**

## 特徴

- **7人の占い師**：老賢者 / ギャル占い師 / 毒舌占い師 / やさしい母 / 関西の商売人 / 闇の眷属（中二病）/ AI執事。同じ問いでも口調がガラッと変わる
- **“それっぽさ”の設計**：お告げは「①バーナム効果（見透かしの一言）＋②問いの語をひろう核心＋③ちょい毒のオチ」の3段で生成
- **演出**：吉凶で球が発色 / ドラムロール音 & 確定チャイム（Web Audioで合成、音源ファイル不要）/ 吉のときは紙吹雪
- **依存ゼロ**：フレームワークなし。1枚のHTMLで完結

## 背景

「診断・占いメーカーはなぜバズるのか」を年代順にたどった調査（脳内メーカー〜Picrew〜AI占い）から、
その原型のひとつ「マジック8ボール」を令和版として作った習作。
バズの背骨（自分ごと化・意外性・シェア衝動・低コスト）をそのまま仕様に落としている。

> Phase 2 構想：回答生成を本物の Claude API に差し替え、結果カードのOGP画像化まで。

## 技術

`HTML` `CSS` `JavaScript` `Web Audio API` `Canvas`

```bash
open index.html   # ブラウザで直接開くだけで動きます
```
